FolioPort Privacy Policy

Static Portfolio Generator

Last Updated: December 2025

Overview

FolioPort is a static portfolio generator that converts public GitHub data into a personal website. It sources information from your public GitHub profile to create a stunning portfolio site.

Information Collected

Data You Provide

  • GitHub username
  • Custom content (bio, links, descriptions)
  • Personalization settings

Public GitHub Data

FolioPort reads only publicly available GitHub information:

  • Public repositories
  • Stars and forks
  • Programming languages used
  • Public contributions
  • README files

Data FolioPort Never Accesses

FolioPort NEVER accesses:
  • Private repositories
  • GitHub authentication tokens
  • Email addresses
  • Sensitive project information
  • Private gists or notes

Data Storage

The generated portfolio is a static website. No persistent data is stored on our servers.

Generated Files: Stored temporarily during generation, then deleted

User Input: Not stored unless you explicitly save a project configuration

Analytics: None collected by FolioPort

Hosting Your Portfolio

You own and host the generated portfolio. Hosting providers may have their own privacy policies:

  • GitHub Pages
  • Vercel
  • Netlify
  • Your own server

Consult their privacy policies for information about how they handle your portfolio data.

Third-Party Services

FolioPort reads data from GitHub's public API. Refer to GitHub's Privacy Policy for details about their data handling.
