GitPlus Privacy Policy

Last Updated: December 2025

Overview

GitPlus is a VS Code extension that enhances local Git workflows by providing additional UI features such as commit renaming and file history visualization.

Information Collected

GitPlus does not collect, store, or transmit any personal data.

All operations (renaming commits, reading Git history) happen locally on your machine, using the local Git CLI.

We do not collect:

  • Source code
  • Commit content
  • File names
  • Usage data
  • Personal identifiers
  • Telemetry or analytics

Data Storage

GitPlus stores no data. VS Code and Git themselves may store settings, logs, or cache — GitPlus does not access or transmit these.

Third-Party Services

None. No analytics, no telemetry, no remote servers.

Permissions

GitPlus requests only the minimum permissions necessary to function with VS Code's native Git integration. It does not request permission to access your file system, network, or any external services.
