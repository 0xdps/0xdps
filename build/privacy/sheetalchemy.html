SheetAlchemy Privacy Policy

Python Library for Google Sheets

Last Updated: December 2025

Overview

SheetAlchemy is a Python library that provides a programmatic interface for interacting with Google Sheets. It allows developers to read, write, and manage spreadsheets through code.

Information Collected

SheetAlchemy does not collect or store any user data.

SheetAlchemy is a library that runs entirely on your machine. It does not transmit telemetry, usage data, or any information to external servers.

Data Handling

If you configure Google API keys, OAuth tokens, or sheet data, it stays:

  • In your user code
  • On your infrastructure
  • Under your control

No External Logging

The library performs no external logging, telemetry, or transmission of any kind. All operations are local to your Python environment.

Third-Party Services

SheetAlchemy communicates with Google Sheets APIs when you explicitly call it. Refer to Google's Privacy Policy for information about how Google handles data sent through their APIs.

Google Authentication

When you use OAuth authentication with Google, you control:

  • Which credentials are used
  • What permissions you grant
  • Which sheets you connect to

SheetAlchemy never stores or transmits your credentials to any third party.
