PingPong Browser Extension Privacy Policy

Last Updated: December 2025

Overview

PingPong is a browser extension that helps developers test APIs, send HTTP requests, manage histories, and use collections—similar to a lightweight Postman alternative.

Data Collected

Stored Locally Only

All user data stays on your device:

  • Request history
  • Collections
  • Environment variables (if any)
  • Custom headers and settings

All data is kept inside your browser's local storage or extension storage. Nothing is uploaded unless explicitly configured by you.

Data Never Collected

  • Personal identity information
  • Your APIs' request/response content
  • Tokens or secrets (unless you store them locally yourself)
  • Browsing history
  • Email addresses or personal data

Data Sharing

PingPong does not transmit data to third-party servers.

The only outgoing data is:

  • Requests you intentionally send to your own APIs
  • Error logs sent optionally (only if you explicitly enable reporting)

Browser Permissions

storage — To save your collections & history locally

tabs / activeTab — For UI interactions and context

http://*/* / https://*/* — To allow sending requests to any API endpoint

Important: PingPong does not inspect or track your browsing activity. These permissions only enable the features you explicitly use.

Third-Party Services

None. PingPong does not rely on external services, analytics platforms, or cloud storage.
