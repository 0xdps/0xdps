Mockly Privacy Policy

Mock API Service for Developers

Last Updated: December 2025

Overview

Mockly is a mock API service that provides developers with mock endpoints, dynamic responses, and debugging utilities for API development and testing.

Information Collected

Operational Logs

For service reliability and security, we may log:

  • Request timestamps
  • IP addresses (standard web server logging)
  • Requested endpoints
  • Error traces (for debugging)
Important: Logs are for debugging and abuse prevention only. No profiling or personalization occurs.

Data You Send to Mockly

Customer data sent via API requests is processed in memory and not retained unless explicitly requested with "log mode" for debugging purposes.

Personal Data

Mockly does not collect personal identifiable information (PII) unless you explicitly configure it to log request bodies for debugging.

User Accounts (Future)

If Mockly supports authentication or user accounts in the future, a separate privacy policy update will be published detailing data collection.

Third-Party Services

Hosting: Vercel or Fly.io

Optional Analytics: Privacy-respecting analytics (if enabled)

No tracking or profiling: We do not share user data with advertisers or data brokers

Data Retention

Operational logs are typically retained for up to 30 days for debugging and security purposes. Custom data is not retained unless explicitly stored by the user.
