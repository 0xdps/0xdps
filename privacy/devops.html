Azure DevOps Organization Privacy Policy

0xDPS Organization

Last Updated: December 2025

Overview

The 0xDPS Azure DevOps organization is used internally for managing repositories, pipelines, CI/CD, and collaboration across projects. This policy explains how data is handled within this organization.

Information Collected

Azure DevOps may display and process the following information for organization members and contributors:

  • Contributor names
  • Email addresses (associated with accounts)
  • Commit metadata and history
  • Branch information
  • Build and deployment logs
  • Issue tracking and work items

Data Control

Important: This data is controlled by Microsoft, not by 0xDPS directly. 0xDPS does not collect or share any personal data beyond what Azure DevOps' standard infrastructure requires.

Data Usage

Data is used solely for:

  • Repository and code management
  • Identity verification and access control
  • Build and deployment pipelines
  • Issue tracking and project management
  • Team collaboration

0xDPS does not use this data for: commercial purposes, profiling, or analytics.

Access Control

Organization Members: Only explicitly invited users may access the organization

Guest Access: Guests may access specific projects as permitted

Removal: Members or guests may request removal at any time

Third-Party Services

Azure DevOps is hosted and managed by Microsoft. For information about how Microsoft handles data, refer to the Microsoft Privacy Statement.

Security

0xDPS follows Azure DevOps security best practices:

  • Authentication via Microsoft accounts
  • Role-based access control (RBAC)
  • Encryption in transit and at rest
  • Regular security reviews

User Rights

Members may request:

  • Information about data stored in the organization
  • Removal from the organization
  • Deletion of personal data (subject to legal retention requirements)

Contact

Changes to This Policy

This policy may be updated as the organization evolves or as Microsoft updates Azure DevOps services. Updates will be reflected on this page.
